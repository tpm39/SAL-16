
SAL-16 is a 16-Bit Computer available in both Logisim & Verilog.

There is also an Assembler, Linker, Compiler & Emulator for SAL-16 written in Python.

Please see 'Notes.txt' for an overview as to what's what.

SAL-16 is based on Ross McGowan's 'Design a CPU' & 'Design a FPU' courses, see:

https://www.patreon.com/cw/RossMcgowanMaths

https://www.appliedmathematics.co.uk
